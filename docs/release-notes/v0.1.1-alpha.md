## 0.1.1-alpha 更新一览(2026-10-31)

### 🚀 功能追加

- *core*: 远程规则源管理器 —— HTTP(S) 拉取（10s/20s 超时、5MB 上限、重定向、ETag/Last-Modified 条件请求 → 304）、三种格式解析（Dev-Sidebike JSON / Shadowrocket `.conf` / 域名列表与 hosts）、幂等合并（Sidebike JSON、域名单、hosts 与 adblock 语法）
- *core*: 规则引擎支持 `abort`（直接拒绝，用于广告/跟踪域名）与 `disabledIntercepts`（删除内置规则后持久化不还原）；MITM 需要但 CA 不可用时按域名降级直连，握手失败输出“不信任用户 CA”诊断
- *core/dns*: DNS 加固 —— Provider 健康检查、境外域名 DoH/DoT 优先 + 可信源/对照源共识防污染、私有/保留 IP 拒收、单 Provider 硬超时与并行 race、失败回退预置 IP、失败/污染结果不缓存、未验证结果短 TTL、DoT/DoH 诱饵 SNI 被拒自动回退真实 SNI
- *app*: 日志导出 —— `.log`/`.txt` 文本文件与诊断调试包 `.zip`（设备/网络/配置/状态/日志/诊断/环境信息），系统文件选择器保存，保留剪贴板兜底；自动脱敏 Authorization/Cookie/Token
- *app*: 网络诊断 —— DNS Provider 健康、真实域名解析结果、直连 TCP+TLS、本地代理 CONNECT/GET、系统代理/Private DNS/lockdown/MITM/CA 状态与 tun 丢包计数，输出可读结论并附最近日志
- *app*: CA 安装流程重做 —— 与 MITM 开关无关地生成 CA；KeyChain 系统安装 Intent + 系统凭据设置兜底；展示 SHA-256 指纹与 subject；锁屏未设置时先引导设置锁屏；安装返回后重试检测并区分“已取消/未检测到/已安装”；支持导出 `.crt`
- *app*: MITM 开关 CA 门禁与旧配置迁移 —— 未检测到 CA 时拒绝开启；0.1.0 旧配置若处于 MITM 开而 CA 未装状态，启动时自动降级直连并持久化，避免境外 HTTPS 全部失败
- *app*: 规则编辑 API —— 新增/编辑/删除拦截规则（SNI 伪装、镜像目标、拦截）、直连放行列表、国内域名列表、文本导入、远程规则源刷新、内置规则禁用持久化
- *ui*: 规则页重构为四个标签（拦截规则 / 直连放行 / 国内域名 / 规则源），支持搜索、计数、添加/编辑/删除、从文本或 URL 导入、一键添加推荐规则源（Johnshall/Shadowrocket-ADBlock-Rules-Forever，运行期拉取，CC BY-SA 4.0 致谢）
- *ui*: 设置页新增网络诊断、DNS hosts 编辑、DNS 详情只读视图（Provider/mapping/familyMapping/preSetIp 计数）、超时三档预设、规则源/日志导出入口
- *qa*: 0.1.1 自动化 flow（smoke / progress / nav / ca / mitm / export / rules / import）与 hermetic 远程规则源服务（ETag→304、故障注入、10.0.2.2 访问）

### 🐛 问题修复

- *app*: 修复日志导出只能复制大段文本、无法得到文件的问题

- *ui*: 修复规则卡片展开/收起动画与其他卡片位移动画不同步
- *ui*: 修复含首页的页面切换时新旧页面重叠显示（改为顺序 fade-through）
- *ui*: 启动/停止状态仅保留一个进度指示；移除“加速时长”展示
- *ui*: 修复国内域名与直连放行列表不可查看/不可编辑

### 安装与已知限制

- 安装下方 Assets 中的 `Dev-Sidebike-0.1.1-alpha-release.apk`（自签名，需允许未知来源），首次启动按引导授予 VPN 权限。
- 仅 ARM 双 ABI（arm64-v8a / armeabi-v7a）；建议 Android 10+（API 29+ 才有系统 HTTP 代理，Android 8–9 仅 DNS 模式）。
- 默认仅 DNS 防污染对全部应用生效；不遵循系统代理的应用不会经过 HTTP 代理。
- MITM 增强默认关闭，开启需安装用户 CA（系统要求先设置锁屏），且 Android 7+ 多数第三方应用不信任用户 CA。
- 规则源导入仅映射 DIRECT→直连放行、REJECT→拦截；PROXY、IP-CIDR/GEOIP/RULE-SET 等复杂类型会被跳过并给出警告（本版本无远端节点/递归规则集）。
- 删除内置拦截规则会记录到 `disabledIntercepts` 持久化；重置配置可恢复内置规则。
- 系统「私人 DNS」(Private DNS/DoT) 开启会绕过 VPN DNS，应用内会提示关闭。
- 真机（尤其 MIUI/HyperOS）后台保活与厂商 ROM 差异请按 `_script/qa/device_verify.md` 复验；如仍遇到境外站点无法访问，请在 App 内「设置 → 运行网络诊断」后导出诊断包反馈。
- 校验和见 Assets 中的 `SHA256SUMS.txt`；完整测试报告见仓库 `FINAL-REPORT.md` 与 `docs/qa/05-test-report.md`。
