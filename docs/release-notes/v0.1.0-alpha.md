Dev-Sidebike 0.1.0-alpha is the first alpha of an Android rewrite of Dev-Sidecar: it provides system-wide anti-poisoning DNS and a system HTTP proxy through VpnService, accelerating access to GitHub and other oversea developer resources on Android. This release ships a complete Kotlin backend (multi-provider DNS, rule engine, HTTP/HTTPS proxy, CA/MITM), system-level VpnService integration (DNS interception + Android 10+ system proxy + fail-safe), a strict Material 3 UI with non-linear motion, plus a full three-stage build/test/delivery pipeline and thorough feasibility documentation. ARM only (arm64-v8a / armeabi-v7a); MITM is disabled by default. Please read the known limitations before installing.

## 0.1.0-alpha 更新一览(2026-10-31)

### 🚀 功能追加

- *core*: 纯 Kotlin 后端内核 —— 多 Provider DNS 防污染（UDP / DoH / DoT + 预置 IP + 诱饵 SNI）、官方规则快照（69 域名 / 77 路径规则 / 61 域预置 IP / 1237 条国内域名）、规则引擎、HTTP/HTTPS CONNECT 代理、BouncyCastle CA 与 MITM、统计与日志、引擎门面
- *app*: 系统级 VpnService 接入 —— tun 内 DNS 拦截（`10.111.0.2:53`）+ Android 10+ `setHttpProxy` 系统代理 + 前台服务（specialUse）+ always-on VPN + 开机自启 + 通知权限引导
- *app*: 启动与运行故障安全 —— 本地代理自检、DNS 就绪自检（不可用则拒绝接管网络）、看门狗自动拆 VPN、端口冲突回退、Private DNS / lockdown / 其他 VPN 检测与提示
- *ui*: 严格 Material Design 3 前端五屏（首页 / 规则 / 日志 / 设置 / 证书引导），深色模式与动态取色，全部状态变化使用 MD3 非线性动画（72 处动画 / 36 处运动 token）
- *pipeline*: 三环境构建流水线 `dev → test → prod`（预交付物 → 测试门禁 → 交付物，失败禁止晋级），含单测门禁、MD3/动画静态审计、APK 结构校验、需求结构校验与 build-info 强一致性校验
- *qa*: 独立 QA 门禁 —— 模拟器自动化 smoke（系统代理 / DNS 防污染 / 停止恢复）、故障注入验证（杀 proxy / 杀 engine）、对抗 fuzz（VPN 编解码 8 例 + HTTP/DNS/配置 9 例）与 release 交付门禁脚本

### 安装与已知限制

- 安装下方 Assets 中的 `Dev-Sidebike-0.1.0-alpha-release.apk`（自签名，需允许未知来源），首次启动按引导授予 VPN 权限。
- 仅 ARM 双 ABI（arm64-v8a / armeabi-v7a）；建议 Android 10+（API 29+ 才有系统 HTTP 代理，Android 8–9 仅 DNS 模式）。
- 默认仅 DNS 防污染对全部应用生效；不遵循系统代理的应用不会经过 HTTP 代理。
- MITM 增强默认关闭，开启需安装用户 CA，且 Android 7+ 多数第三方应用不信任用户 CA。
- 系统「私人 DNS」(Private DNS/DoT) 开启会绕过 VPN DNS，应用内会提示关闭。
- 真机（尤其 MIUI/HyperOS）后台保活与厂商 ROM 差异请按 `_script/qa/device_verify.md` 复验。
- 校验和见 Assets 中的 `SHA256SUMS.txt`；完整测试报告见仓库 `FINAL-REPORT.md` 与 `docs/qa/05-test-report.md`。
