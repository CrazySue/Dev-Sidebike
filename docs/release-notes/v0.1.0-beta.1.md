Dev-Sidebike 0.1.0-beta.1 is the first beta of an Android rewrite of Dev-Sidecar: it provides system-wide anti-poisoning DNS and a system HTTP proxy through VpnService, accelerating access to GitHub and other oversea developer resources on Android. This release ships a complete Kotlin backend (multi-provider DNS, rule engine, HTTP/HTTPS proxy, CA/MITM), system-level VpnService integration (DNS interception + API 29+ system proxy + fail-safe), a strict Material 3 UI with non-linear motion, plus a full three-stage build/test/delivery pipeline and thorough feasibility documentation. ARM only (arm64-v8a / armeabi-v7a); MITM is disabled by default. Please read the known limitations before installing.

## 0.1.0-beta.1 更新一览(2026-10-25)

### 🚀 功能追加

- *core*: 纯 Kotlin 重写 Dev-Sidecar 后端内核 —— 多 Provider DNS 防污染（UDP / DoH / DoT + 预置 IP + 诱饵 SNI）、官方规则快照（69 域名 / 77 路径规则 / 61 域预置 IP / 1237 条国内域名）、规则引擎、HTTP/HTTPS CONNECT 代理、BouncyCastle CA 与 MITM、统计与日志、引擎门面
- *app*: VpnService 系统级接入 —— tun 内 DNS 拦截（`10.111.0.2:53`）+ API 29+ `setHttpProxy` 系统代理 + 前台服务（specialUse）+ always-on VPN + 开机自启 + 通知权限引导
- *app*: 启动/运行故障安全 —— 本地代理自检、DNS 就绪自检（不可用则拒绝接管网络）、看门狗自动拆 VPN、端口冲突回退、Private DNS / lockdown / 其他 VPN 检测与提示
- *ui*: 严格 Material 3 前端五屏（首页 / 规则 / 日志 / 设置 / 证书引导），深色模式与动态取色，全部状态变化使用 MD3 非线性动画（72 处动画 / 36 处运动 token）
- *pipeline*: 三环境流水线 `dev → test → prod`（预交付物 → 测试门禁 → 交付物，失败禁止晋级），含单测门禁、MD3/动画静态审计、APK 结构校验、需求结构校验与 build-info 强一致性校验
- *qa*: 独立 QA 门禁 —— 模拟器自动化 smoke（E1 系统代理 / E2 DNS 防污染 / 停止恢复）、故障注入验证（杀 proxy / 杀 engine）、对抗 fuzz（VPN 编解码 8 例 + HTTP/DNS/配置 9 例）与 release 交付门禁脚本

### 🐛 问题修复

- *build*: 修复 Android SDK 平台/构建工具体安装与 AGP 兼容问题；Gradle 全局构建锁在进程被 kill 后残留（AbandonedMutexException）导致全队构建失败；Kotlin DSL 中 `java.time` 被扩展遮蔽导致的脚本编译失败
- *app*: 修复 VPN 开启后临时系统解析器导致的"全设备 DNS 黑洞"（集成真实 DNS 解析器 + 启动前 DNS 就绪自检）；修复内置官方规则未加载导致规则页为空；修复 tun DNS 应答超 MTU 时置 TC 引发的 TCP:53 重试超时（改为裁剪答案、永不置 TC）；补齐通知运行时权限请求
- *proxy*: 修复 MITM 关闭时镜像（MIRROR）规则导致的 HTTPS 证书不匹配（降级为直连）；移除系统 DNS 回退以规避 VPN DNS 回环；修复长连接期间上下行字节统计为 0
- *ui*: 修复端口设置对话框的无限组合/动画导致的测试与输入卡死；修复导航测试语义歧义；修复 RUNNING 状态仍显示"请先启动"的 CA 文案；首页状态去重与能力行重构

### 🚜 重构

- *backend*: 后端由 Node.js/Electron 内核（不可运行于 Android）重构为纯 Kotlin/JVM 实现，模块边界与配置语义对齐上游，不携带 Node 运行时
- *proxy*: CONNECT 路由决策统一为规则引擎 `plan()`（DIRECT / MIRROR / REJECT / SYNTHETIC），MITM 仅在规则需要 HTTP 层改写时启用

### 👀 优化改进

- *ui*: 首页 hero 状态信息密度优化（唯一状态标签 + 连接时长 + 真实能力行）、统计数字动画、字节未知时显示 `—` 而非 `0 B`
- *ui*: 规则页搜索/计数/空态与"重新加载配置"、日志页级别筛选/自动滚动/导出诊断、证书引导四步错峰入场
- *app*: 端口占用时自动回退高位端口并在 UI 如实显示；Private DNS / lockdown / 系统代理未注册等环境横幅提示

### 安装与已知限制

- 安装下方 Assets 中的 `Dev-Sidebike-0.1.0-beta.1-release.apk`（beta 自签名，需允许未知来源），首次启动按引导授予 VPN 权限。
- 仅 ARM 双 ABI（arm64-v8a / armeabi-v7a）；建议 Android 10+（API 29+ 才有系统 HTTP 代理，Android 8–9 仅 DNS 模式）。
- 默认仅 DNS 防污染对全部应用生效；不遵循系统代理的应用不会经过 HTTP 代理。
- MITM 增强默认关闭，开启需安装用户 CA，且 Android 7+ 多数第三方应用不信任用户 CA。
- 系统「私人 DNS」(Private DNS/DoT) 开启会绕过 VPN DNS，应用内会提示关闭。
- 真机（尤其 MIUI/HyperOS）后台保活与厂商 ROM 差异请按 `_script/qa/device_verify.md` 复验。
- 校验和见 Assets 中的 `SHA256SUMS.txt`；完整测试报告见仓库 `FINAL-REPORT.md` 与 `docs/qa/05-test-report.md`。
